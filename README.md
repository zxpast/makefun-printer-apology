One line, from an office printer that has finally had enough:

> I'm sorry I jammed, printed your salary slip twice, and kept the original — consider it my severance package.

It starts as an apology — jammed, double-printed the salary slip —
and ends with the printer keeping the original as its severance. The
final two words flip the whole note: what looked like a sorry letter
is really a resignation demand from an employee who was never paid.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` drops that one line into `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22, standard library only, and
fully deterministic — the same bytes every run, with no network, no
clock and no randomness. The line runs 109 characters, inside the
1–120 gate, on a single line, in UTF-8.
